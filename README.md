# Responsive Student Dashboard

A responsive student dashboard web application developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Project Overview

The Responsive Student Dashboard is designed to provide students with a simple and user-friendly platform to manage their academic activities.

The system includes student login, dashboard, courses, assignments, progress tracking, profile management, messages, and settings.

## Features

- Student Login and Signup
- Responsive Dashboard
- Course Management
- Assignment Management
- Assignment Submission
- Course Progress Tracking
- Student Profile
- Messages and Notifications
- Settings
- Responsive Design for Different Screen Sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- Chart.js

## Database

The project uses MySQL for storing student, course, assignment, submission, and progress-related data.

The database backup is included as:

`student_dashboard.sql`

## Project Structure

- `*.php` – Backend and application pages
- `*.css` – Styling and responsive design
- `uploads/` – Assignment and question files
- `student_dashboard.sql` – MySQL database backup

## Responsive Design

The dashboard is designed to work across different screen sizes using responsive CSS techniques, including the `@media` rule.

## Purpose

This project was developed as an academic project to demonstrate responsive web design, PHP-based web development, database integration, and student dashboard functionality.
